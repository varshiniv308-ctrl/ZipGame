# 🎮 ZipGame

ZipGame is an Android puzzle game inspired by LinkedIn's Zip puzzle. Connect numbered checkpoints through a continuous path while solving logic-based challenges.

## ✨ Features
- Number-connection puzzle gameplay
- Clean and modern UI
- Undo, Hint, and Restart
- Progress tracking

## 🛠️ Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- Android Studio

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/varshiniv308-ctrl/ZipGame.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle and run the app on an emulator or Android device.
